# 하나의 창에서 일곱 가지 유틸을 여는 법

PC를 새로 맞출 때 필수 유틸을 하나씩 깔던 시간, KOTU라면 그대로 아낄 수 있습니다.

## 이런 분께 추천

- MIT 오픈소스 — GitHub에서 소스 공개
- 한글 우선 UI + 영문 가이드 병행
- 사용자 범위 설치라 관리자 권한 불필요, 탐색기 통합도 자유롭게
