# 사진·영상·음악·문서·압축·모니터를 한 번에

코덱 팩 찾아 헤매던 시절은 이제 끝. KOTU는 필요한 엔진을 전부 품고 있습니다.

## 이런 분께 추천

- 한글 우선 UI + 영문 가이드 병행
- MIT 오픈소스 — GitHub에서 소스 공개
- 코덱 팩·별도 설치 불필요 — 7-Zip, libvlc, 하드웨어 모니터 엔진 동봉

## 오디오 모듈

다운로드는 GitHub Releases에서 받으실 수 있습니다. 사용해 보시고 피드백 남겨주시면 감사하겠습니다.
