# 윈도우 새로 깔면 제일 먼저 까는 앱

파일 형식마다 다른 프로그램을 열어야 했던 번거로움, KOTU 하나로 정리됩니다.

## 이런 분께 추천

- 사용자 범위 설치라 관리자 권한 불필요, 탐색기 통합도 자유롭게
- 한글 우선 UI + 영문 가이드 병행
- 설치판(자동 업데이트)과 포터블(무설치) 모두 제공

## 이미지 모듈

이미지도 빼놓을 수 없는데, jpg·png·gif·webp·bmp·tif·ico·psd, 줌 10~800%, GIF 애니메이션.
