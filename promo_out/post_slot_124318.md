# 코덱 팩 없이 받자마자 쓰는 윈도우 유틸

## 이런 분께 추천

- MIT 오픈소스 — GitHub에서 소스 공개
- 한글 우선 UI + 영문 가이드 병행
- 설치판(자동 업데이트)과 포터블(무설치) 모두 제공

GitHub Releases 링크에서 설치판 또는 포터블을 받아 바로 써보실 수 있습니다.
