# 설치판도 포터블도 무료 — KOTU 소개

윈도우를 새로 설치할 때마다 여러 유틸을 따로 설치하셨나요? KOTU는 이걸 하나로 합쳤습니다.

## 이런 분께 추천

- 사용자 범위 설치라 관리자 권한 불필요, 탐색기 통합도 자유롭게
- 한글 우선 UI + 영문 가이드 병행
- 설치판(자동 업데이트)과 포터블(무설치) 모두 제공
