# 코덱 팩 없이 받자마자 쓰는 윈도우 유틸

코덱 팩 찾아 헤매던 시절은 이제 끝. KOTU는 필요한 엔진을 전부 품고 있습니다.

## 이런 분께 추천

- 코덱 팩·별도 설치 불필요 — 7-Zip, libvlc, 하드웨어 모니터 엔진 동봉
- 한글 우선 UI + 영문 가이드 병행
- 사용자 범위 설치라 관리자 권한 불필요, 탐색기 통합도 자유롭게

## H/W Info 모듈

특히 H/W Info 모듈이 인상적입니다 — CPU·GPU·RAM·SSD 실시간 그래프, 사양 전체 복사.
