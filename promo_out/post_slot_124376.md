# 윈도우 새로 깔면 제일 먼저 까는 앱

파일 형식마다 다른 프로그램을 열어야 했던 번거로움, KOTU 하나로 정리됩니다.

## 이런 분께 추천

- 한글 우선 UI + 영문 가이드 병행
- 설치판(자동 업데이트)과 포터블(무설치) 모두 제공
- 코덱 팩·별도 설치 불필요 — 7-Zip, libvlc, 하드웨어 모니터 엔진 동봉

## H/W Info 모듈

H/W Info도 빼놓을 수 없는데, CPU·GPU·RAM·SSD 실시간 그래프, 사양 전체 복사.
