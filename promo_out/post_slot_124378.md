# 코덱 팩 없이 받자마자 쓰는 윈도우 유틸

파일 형식마다 다른 프로그램을 열어야 했던 번거로움, KOTU 하나로 정리됩니다.

## 이런 분께 추천

- 한글 우선 UI + 영문 가이드 병행
- 코덱 팩·별도 설치 불필요 — 7-Zip, libvlc, 하드웨어 모니터 엔진 동봉
- 사용자 범위 설치라 관리자 권한 불필요, 탐색기 통합도 자유롭게

## 문서 모듈

문서도 빼놓을 수 없는데, txt·md·html·log·ini 편집 + PDF 보기, 인코딩 변환.
