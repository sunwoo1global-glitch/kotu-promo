# 윈도우 새로 깔면 제일 먼저 까는 앱

윈도우를 새로 설치할 때마다 여러 유틸을 따로 설치하셨나요? KOTU는 이걸 하나로 합쳤습니다.

## 이런 분께 추천

- MIT 오픈소스 — GitHub에서 소스 공개
- 코덱 팩·별도 설치 불필요 — 7-Zip, libvlc, 하드웨어 모니터 엔진 동봉
- 한글 우선 UI + 영문 가이드 병행

## 비디오 모듈

특히 비디오 모듈이 인상적입니다 — mp4·mkv·avi·webm·mov·wmv 등 13종, 자막 자동 변환, 이어보기.
